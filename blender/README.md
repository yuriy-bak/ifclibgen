# IFC Library Tools для Blender

Аддон для Blender + Bonsai: стыковка элементов по портам и превращение меша в тип IFC-библиотеки. Ядро `ifclibgen` упаковано внутрь аддона, отдельно ставить не нужно.

## Сборка и установка

```
python blender/build.py        # → dist/ifclibgen_blender-<версия>.zip
```

Edit ▸ Preferences ▸ Get Extensions, затем меню ⌄ справа вверху ▸ Install from Disk…, выбрать zip. Нужен включённый Bonsai (проверено на 0.9.1 unstable, Blender 5.2).

Панель: 3D-вид, боковая панель (N), вкладка **IFC Lib**.

Папка библиотеки задаётся в настройках аддона (Preferences ▸ Add-ons ▸ IFC Library Tools). Если пусто — папка `libraries` Bonsai, тогда файлы сразу видны в выпадающем списке Project Library.

## Состыковать

1. [Object] Выдели элемент, к которому стыкуешь, затем Shift+клик по элементу, который нужно передвинуть (активный двигается).
2. Dock.

Выбирается свободная пара портов: сначала совпадающие по форме и размеру, с встречным направлением потока, потом ближайшая. Порты соединяются (как Connect в Bonsai).

Если пара не та или изделие развёрнуто не так — панель Adjust Last Operation слева внизу (или F9): **Port pair** — следующая пара, **Extra turn around port axis** — доворот на 90/180/270°.

Поворот элемента сохраняется: применяется только тот поворот, который нужен, чтобы порты смотрели друг на друга. У круглых портов поворот вокруг оси не меняется (повернул пленум по Z — так и останется), прямоугольные доворачиваются до ближайшего положения, где стороны совпадают.

## Меш → тип IFC

1. [Object] Выдели обычный меш (не IFC-элемент). Origin меша = точка установки типа (Object ▸ Set Origin), оси меша = оси типа.
2. Заполни Name, IFC class, Predefined type, Group (имя файла библиотеки), при желании Manufacturer, Model, Insertion point.
3. [Edit] Режим граней (3 на основной клавиатуре), выдели одну грань присоединения, затем Add port on selected face. Порт ставится в центр грани, стрелка наружу, размер и форма (круг/прямоугольник) определяются по грани. Повтори для остальных присоединений.
4. Кнопкой-курсором в списке портов выдели порт и поправь размер, направление потока, систему.
5. [Object] Write to Library.

Что получится:
- пакет `<папка библиотеки>/packages/<group>/<имя>/` (тот же формат, что у командной строки);
- пересобранный файл `<папка библиотеки>/<group>.ifc` со всеми типами группы;
- с галочкой «Put into project instead of the mesh» тип сразу добавляется в открытый проект, экземпляр встаёт на место меша, меш и порты скрываются.

Материалы меша становятся цветами типа. Масштаб объекта учитывается, поворот и положение — нет (они задают систему координат типа).

Повторная запись с тем же именем обновляет библиотеку, но тип, уже добавленный в проект, пока не обновляется — это будет кнопка «Обновить типы из библиотеки».

# IFC Library Tools для Blender

Аддон для Blender + Bonsai: стыковка элементов по портам, превращение меша в тип IFC-библиотеки и обновление типов в проекте из библиотеки. Ядро `ifclibgen` упаковано внутрь аддона, отдельно ставить не нужно.

## Установка с автообновлением

Edit ▸ Preferences ▸ Get Extensions, затем Repositories (выпадающий список справа вверху) ▸ + ▸ Add Remote Repository:
- URL: `https://yuriy-bak.github.io/ifclibgen/index.json`
- галочка Check for Updates on Startup.

Затем в списке Get Extensions найди IFC Library Tools и нажми Install. Новые версии Blender покажет сам, обновление одной кнопкой. Нужен включённый Bonsai.

## Сборка и установка вручную

```
python blender/build.py        # → dist/ifclibgen_blender-<версия>.zip
```

Edit ▸ Preferences ▸ Get Extensions, затем меню ⌄ справа вверху ▸ Install from Disk…, выбрать zip. Нужен включённый Bonsai (проверено на 0.9.1 unstable, Blender 5.2).

Панель: 3D-вид, боковая панель (N), вкладка **IFC Lib**.

Папка библиотеки задаётся в настройках аддона (Preferences ▸ Add-ons ▸ IFC Library Tools). Если пусто — папка `libraries` Bonsai, тогда файлы сразу видны в выпадающем списке Project Library.

## Состыковать

1. [Object] Выдели элемент, к которому стыкуешь, затем Shift+клик по элементу, который нужно передвинуть (активный двигается).
2. Dock.

Нужный порт можно указать: выдели элемент, затем Bonsai ▸ Show Ports, и вместо элемента выделяй стрелку его порта. Например, клик по стрелке порта на целевом элементе, затем Shift+клик по стрелке порта на передвигаемой детали, затем Dock. Можно указать порт только на одном элементе, на втором порт подберётся сам.

Выбирается свободная пара портов: сначала совпадающие по форме и размеру, с встречным направлением потока, потом ближайшая. Порты соединяются (как Connect в Bonsai).

Если пара не та или изделие развёрнуто не так — панель Adjust Last Operation слева внизу (или F9): **Port pair** — следующая пара, **Extra turn around port axis** — доворот на 90/180/270°, **Flip direction** — порт детали смотрит в ту же сторону, что и целевой (если стрелка порта направлена внутрь тела).

Поворот элемента сохраняется: применяется только тот поворот, который нужен, чтобы порты смотрели друг на друга. У круглых портов поворот вокруг оси не меняется (повернул пленум по Z — так и останется), прямоугольные доворачиваются до ближайшего положения, где стороны совпадают.

## Меш → тип IFC

1. [Object] Выдели обычный меш (не IFC-элемент). Origin меша = точка установки типа (Object ▸ Set Origin), оси меша = оси типа.
2. Заполни Name, IFC class, Predefined type, Group (имя файла библиотеки), при желании Manufacturer, Model, Insertion point.
3. [Edit] Режим граней (3 на основной клавиатуре), выдели одну грань присоединения, затем Add port on selected face. Порт ставится в центр грани, стрелка наружу, размер и форма (круг/прямоугольник) определяются по грани. Повтори для остальных присоединений.
4. Кнопкой-курсором в списке портов выдели порт и поправь размер, направление потока, систему.
5. [Object] Write to Library.

Что получится:
- пакет `<папка библиотеки>/packages/<group>/<имя>/` (тот же формат, что у командной строки);
- пересобранный файл `<папка библиотеки>/<group>.ifc` со всеми типами группы;
- с галочкой «Put into project instead of the mesh» тип сразу добавляется в открытый проект, экземпляр встаёт на место меша, меш и порты скрываются.

Материалы меша становятся цветами типа. Масштаб объекта учитывается, поворот и положение — нет (они задают систему координат типа).

Повторная запись с тем же именем обновляет библиотеку; тип, уже добавленный в проект, обновляется кнопкой из следующего раздела.

## Обновить типы из библиотеки

Панель **Update types from library** (вкладка IFC Lib).

1. Types: **All** — все типы проекта, сделанные генератором; **Of selected** — типы выделенных элементов.
2. **Check Library Types** — сравнение с файлами `*.ifc` в папке библиотеки (по GlobalId и хэшу содержимого). Видно, какие типы изменились, какие порты сдвинулись, каких типов в библиотеке нет (их не трогаем).
3. Если сдвинулась точка установки (все порты типа сместились одинаково), у типа появляется галочка **Keep position in the model**: включена — элементы сдвигаются так, что остаются на месте; выключена — точка вставки элементов остаётся, тело смещается.
4. **Update Types** — геометрия, свойства и порты типа заменяются; порты элементов передвигаются (не пересоздаются), соединения сохраняются. Ctrl+Z отменяет.

После обновления — список «тип · элемент · этаж: что не так» (например, сдвинулся порт, который был соединён). Клик по строке или **Next** выделяет элемент и показывает его в виде, галочка — «проверено», **Hide checked** прячет проверенные. Отчёт сохраняется рядом с проектом (`<проект>.libupdate.json`), **Load Last Report** открывает его снова.

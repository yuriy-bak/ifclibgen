# Верстак FreeCAD «IFC Library»

Семейство изделий = обычный документ FreeCAD: модель на выражениях, таблица типоразмеров, порты на гранях. Кнопка «Экспорт» прогоняет все типоразмеры и пишет библиотеку IFC тем же ядром `ifclibgen`, что и аддон Blender (пакет + `<группа>.ifc`). Ядро упаковано внутрь верстака.

Проверено на FreeCAD 1.1 (встроенные Python 3.11, IfcOpenShell 0.8.4).

## Установка

```
python freecad/build.py        # → dist/IfcLibGen-<версия>.zip
```

Распаковать в папку Mod FreeCAD (Windows: `%APPDATA%\FreeCAD\v1-1\Mod`, должна получиться `Mod\IfcLibGen`), перезапустить FreeCAD, выбрать верстак **IFC Library**.

## Как устроено семейство

- **LibFamily** — свойства типа: TypeName (шаблон имени, `{Alias}` заменяется размером), IfcClass, PredefinedType, Manufacturer, Model, Group (файл библиотеки), Description, Insertion.
- **Params** — таблица параметров: ячейки с псевдонимами (Alias), на них ссылается модель выражениями, например `=Params.Width`. FreeCAD не принимает в псевдонимы названия единиц (W, H, L, F, A…), поэтому слова: Width, Height, Length, Flange.
- **Sizes** — таблица типоразмеров: строка 1 — псевдонимы из Params, дальше по строке на типоразмер. Необязательный столбец `Name` задаёт имя типа вместо шаблона.
- **Тела** — все итоговые тела (не входящие в другие операции); если часть из них видима — только видимые. Можно задать явно: LibFamily ▸ Bodies. Цвет тела = цвет в IFC.
- **Начало координат документа = точка установки типа**, оси документа = оси типа.

## Кнопки

1. **New family** — добавить LibFamily, Params и Sizes с примером.
2. **Port on face** — выдели грань присоединения и нажми. Порт (LCS) привязан к грани и едет вместе с моделью. Центр, направление (наружу) и размер берутся из грани при каждом экспорте: у кольцевой грани фланца — по отверстию, у круга — диаметр, у прямоугольника — ширина вдоль длинной прямой кромки и высота. В свойствах порта: PortName, Flow (SINK — вход, SOURCE — выход), System, PortShape, Diameter / Width / Height (0 — по грани).
3. **Check family** — прогнать все типоразмеры без записи: пересчёт, порты, имена.
4. **Export family** — записать все типоразмеры в папку библиотеки: `<папка>/packages/<группа>/<модель>/` и `<папка>/<группа>.ifc`. Папку спросит при первом экспорте (сменить: **Library folder…**). Укажи ту же папку, что в аддоне Blender, — тогда «Update types from library» в Bonsai подтянет изменения.

Пример: `freecad/examples/example-damper.FCStd` (выдуманный клапан, собирается скриптом `make_example_damper.py`).
